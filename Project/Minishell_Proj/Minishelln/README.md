# Projet_Systeme_Avance

Ceci est le repository du projet de système avancé de l'année 2024-2025. Il s'agit d'un projet de type shell nommé Minishell. Ce projet a été réalisé par [**@Vladimir**](https://github.com/Vladimir9595) et [**@Alizée**](https://github.com/Dinholu).

## Description

Le but de ce projet est de réaliser un shell minimaliste en langage C. Ce shell doit être capable de lire et d'exécuter des commandes simples, de gérer les erreurs et de gérer les variables d'environnement.

## Fonctionnalités

- Affichage
- Commandes simples
- Variables d'environnement
- Gestion des erreurs
- Gestion des signaux

## Utilisation

Pour utiliser ce shell, il suffit de cloner le repository et de compiler le programme avec les commandes suivante :

```bash
cd Project/Minishell_Proj
mkdir build/ && cd build/
cmake ../Minishelln/
make
./minishell
```
