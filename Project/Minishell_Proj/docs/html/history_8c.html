◆ show_prompt()

void show_prompt ( )

Affiche une invite de commande personnalisée.

Cette fonction génère une invite de commande qui inclut :

  • Le nom de l'utilisateur (variable d'environnement USER).
  • Le nom de l'hôte (variable d'environnement HOSTNAME).
  • Le répertoire courant (obtenu avec getcwd).

Les variables d'environnement USER et HOSTNAME doivent être configurées. Si elles ne le sont pas, des valeurs par défaut ("USER" et "HOSTNAME") seront utilisées.

Exemple de format d'affichage : utilisateur@hôte:/chemin/actuel$

show_prompt(); // Affiche l'invite dans le terminal.
